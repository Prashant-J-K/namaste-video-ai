# NamasteVideo.ai

An AI-powered educational video generation platform.

## Vision

Transform any topic into detailed educational videos with AI-generated explanations, scripts, storyboards, narration and animated visuals.

## Planned Features

- AI-powered topic explanation
- Multiple video depth options
- Detailed script and storyboard generation
- AI narration and captions
- Animated educational diagrams
- Video preview and MP4 export
- Project management and history

## Technology Stack

- React
- Node.js
- Express.js
- Ollama
- Qwen 2.5
- Remotion
- SQLite (planned)

## Project Status

Currently under active development.
